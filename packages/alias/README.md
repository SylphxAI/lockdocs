# lockdocs

Short name for [**@sylphx/lockdocs**](https://www.npmjs.com/package/@sylphx/lockdocs): exact-version library docs for AI agents, straight from your lockfile, offline.

```bash
npx lockdocs zod "reject unknown keys"
npx lockdocs setup
```
