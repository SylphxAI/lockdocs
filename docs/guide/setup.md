# Editors and agents

`npx -y @sylphx/lockdocs setup` writes these for you. To do it by hand:

| Client | Config | Entry |
|---|---|---|
| Claude Code | `claude mcp add --scope user lockdocs -- npx -y @sylphx/lockdocs mcp` | |
| Codex | `~/.codex/config.toml` | `[mcp_servers.lockdocs]` `command = "npx"`, `args = ["-y", "@sylphx/lockdocs", "mcp"]` |
| Cursor | `~/.cursor/mcp.json` | `mcpServers.lockdocs` |
| VS Code | `<config>/Code/User/mcp.json` | `servers.lockdocs` with `"type": "stdio"` |
| Claude Desktop | `<config>/Claude/claude_desktop_config.json` | `mcpServers.lockdocs` |
| Windsurf | `~/.codeium/windsurf/mcp_config.json` | `mcpServers.lockdocs` |
| Gemini CLI | `~/.gemini/settings.json` | `mcpServers.lockdocs` |

`<config>` is `~/.config` on Linux, `~/Library/Application Support` on macOS and `%APPDATA%` on Windows. On Windows the command is `cmd /c npx -y @sylphx/lockdocs mcp`.

### Cursor and VS Code, one click

[![Add to Cursor](https://cursor.com/deeplink/mcp-install-dark.svg)](https://cursor.com/en/install-mcp?name=lockdocs&config=eyJjb21tYW5kIjoibnB4IiwiYXJncyI6WyIteSIsIkBzeWxwaHgvbG9ja2RvY3MiLCJtY3AiXX0%3D) · [Install in VS Code](https://insiders.vscode.dev/redirect?url=vscode%3Amcp%2Finstall%3F%257B%2522name%2522%253A%2522lockdocs%2522%252C%2522command%2522%253A%2522npx%2522%252C%2522args%2522%253A%255B%2522-y%2522%252C%2522%2540sylphx%252Flockdocs%2522%252C%2522mcp%2522%255D%257D)

Requires Node 18+. Confirm the install in your editor, open your project, and enable the server. Both links run `npx -y @sylphx/lockdocs mcp` locally; no API key is needed.

For VS Code from a terminal:

```bash
code --add-mcp '{"name":"lockdocs","command":"npx","args":["-y","@sylphx/lockdocs","mcp"]}'
```

Or add the server to `.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "lockdocs": {
      "command": "npx",
      "args": [
        "-y",
        "@sylphx/lockdocs",
        "mcp"
      ]
    }
  }
}
```

For `.vscode/mcp.json`, use the VS Code `servers` format:

```json
{
  "servers": {
    "lockdocs": {
      "type": "stdio",
      "command": "npx",
      "args": [
        "-y",
        "@sylphx/lockdocs",
        "mcp"
      ]
    }
  }
}
```

## Environment

| Variable | Effect |
|---|---|
| `LOCKDOCS_ROOT` | Project directory when the client sends no roots |
| `LOCKDOCS_FETCH=1` | Allow [fetching](./fetch) exact versions that are not installed |
| `LOCKDOCS_CACHE` | Cache directory (default: the OS cache dir + `/lockdocs`) |
| `LOCKDOCS_NO_STAR_HINT=1` | Turn off the one-time GitHub star line the CLI prints to stderr after the fifth successful interactive run (never shown for the MCP server, with `--json`, in CI, or when stderr is not a terminal) |
| `LOCKDOCS_NO_SYSTEM_PYTHON=1` | Do not ask the system interpreter for its site-packages |
